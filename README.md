# E-Ticaret ve Kullanıcı Yönetim Paneli Uygulaması

## Kısa Açıklama
Bu proje; REST API üzerinden ürün verilerini dinamik olarak çeken, kullanıcı girişi, sepet yönetimi, küresel karanlık/aydınlık tema desteği, profil güncelleme ve anlık ürün arama özelliklerine sahip kapsamlı bir Flutter mobil uygulamasıdır.

## Kullanılan Flutter ve Dart Sürümü
- **Flutter:** 3.44.8 (Channel stable)
- **Dart:** 3.12.2
